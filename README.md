# buildwithsam.co

Canonical personal site for Samarth Gugnani. Static Next.js. Apex host: `https://buildwithsam.co`. `www` 301s to apex via `vercel.json`.

```
cd jobs/landing/site
npm install
npm run dev
npm run build
```

Vercel: set the project root to `jobs/landing/site`, add domain `buildwithsam.co` and `www.buildwithsam.co`.
